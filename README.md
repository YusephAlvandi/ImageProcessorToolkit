# 🧰 ImageProcessor Toolkit

A modular all-in-one desktop suite for batch image processing.

## Tools Included

- **Watermark** - Add text watermarks to images
- **Resizer** - Resize images in bulk
- **Optimizer** - Compress images with size report

## Project Structure

- main.py - Main launcher
- watermark.py - Watermark module
- resizer.py - Resize module
- optimizer.py - Compression module

## How to Run

pip install customtkinter pillow
python main.py

## Tech Stack

Python, CustomTkinter, Pillow, Modular OOP
